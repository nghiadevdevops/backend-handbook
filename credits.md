# Credits

## Four books based on the outlines of ebooks by Huy

The following four books were **rewritten in new words**, based on the outlines of ebooks by the author Huy ([huynt.dev](https://huynt.dev)):

- [Database Indexing](/books/database-indexing/)
- [System Design](/books/system-design/)
- [Web Application Architecture](/books/web-architecture/)
- [Spec-Driven Development](/books/sdd/)

Their content has been corrected and updated to current practice. They are **not copies** of the original ebooks, and this project is **not officially affiliated** with the author. To read the originals, please visit the author's website.

## The other ten books

The remaining ten books are original content: Git Workflow & Branching Strategies, Transactions & Concurrency, Testing Layered & Hexagonal Architectures, API Design, Caching with Redis & Valkey, Messaging & Event-Driven Architecture, Web Application Security, Safe Deployment, Observability & Production Operations, and AI Engineering.

## Versions and fact-checking date

Information about software versions, products, protocol standards and pricing was checked as of **November 2026**. Software changes quickly, so check the official documentation before applying anything in production. Each book lists its exact checking date on its introduction page.
